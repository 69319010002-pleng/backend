
# ระบบจัดการโครงการสิ่งประดิษฐ์ (Invention Project Management System)

ระบบ Backend สำหรับจัดการโครงการสิ่งประดิษฐ์ รองรับการจัดการไฟล์ การส่งโครงการ และการทดสอบ API ผ่าน Swagger

## คุณสมบัติของระบบ (Features)
- **ระบบสมาชิก:** สมัครสมาชิก และ เข้าสู่ระบบ (Login / Register)
- **คลังไฟล์:** จัดเก็บและอัปโหลดไฟล์โครงการ (คล้าย Google Drive)
- **ส่งโครงการสิ่งประดิษฐ์:** แบบฟอร์มบันทึกข้อมูลโครงการพร้อมแนบรูปภาพ และรายละเอียด 5 หัวข้อ
- **API Documentation:** เอกสารอธิบาย API Endpoint ด้วย Swagger UI

## เทคโนโลยีที่ใช้ (Tech Stack)
- **Backend:** Node.js, Express.js
- **API Docs:** Swagger (OpenAPI)
- **Frontend:** HTML, CSS (Tailwind CSS)
